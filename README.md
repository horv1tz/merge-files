# Merge Files

Графическая утилита на Rust (egui): объединяет листы Excel или документы Word
в один файл того же типа либо в PDF.

## Скачать (Windows)
Готовый `merge-files.exe` собирается GitHub Actions: вкладка **Actions → Build → Artifacts**,
а для тегов `v*` (например `v0.1.0`) zip с exe публикуется в **Releases**.

## Возможности
- **Excel** (`.xlsx .xlsm`, а также `.xls .ods` через конвертацию): выбор листов из каждого файла,
  порядок файлов. Листы копируются с форматированием (стили, объединённые ячейки, ширина столбцов, формулы).
  Повторяющиеся имена листов получают префикс из имени файла.
- **Word** (`.docx`, `.doc` через конвертацию): документы идут друг за другом с разрывом страницы;
  переносятся картинки, гиперссылки, недостающие стили и нумерация списков.
  Поля страницы и колонтитулы берутся из первого документа.
- **PDF**, а также чтение `.doc/.xls/.ods` — через LibreOffice; в Windows при его отсутствии
  используется установленный Microsoft Office.
- Перетаскивание файлов в окно, перестановка ⬆⬇, удаление.

## Запуск из исходников
    cargo run --release

Консольный режим (тип результата — по расширению; в Windows release-сборке вывод в консоль не показывается):

    merge-files -o result.pdf a.docx b.docx

Тесты: `cargo test`.
