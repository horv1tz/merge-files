# Merge Files

Программа для Windows (Rust, egui): объединяет листы Excel или документы Word
в один файл того же типа либо в PDF.

## Скачать
Готовый `merge-files.exe` собирает GitHub Actions: **Actions → Build → Artifacts**.
Для тегов `v*` (например `v0.1.0`) zip с exe публикуется в **Releases**.
Установка не нужна — просто запустите exe (Visual C++ Redistributable не требуется).

## Как пользоваться
1. Добавьте файлы кнопкой, перетаскиванием в окно или через контекстное меню проводника.
2. Для Excel отметьте нужные листы (скрытые листы по умолчанию не отмечены), порядок меняется стрелками.
3. Выберите результат — тот же формат или PDF — и нажмите «Объединить…».
4. Предупреждения о том, что не удалось перенести (например, сводные таблицы), показываются под кнопкой;
   готовый файл можно открыть прямо из окна.

## Возможности
- **Excel** (`.xlsx .xlsm`, а также `.xls .ods` через конвертацию): листы копируются с форматированием;
  повторяющиеся имена листов получают префикс из имени файла. Макросы в результат не переносятся.
- **Word** (`.docx`, `.doc` через конвертацию): документы идут друг за другом, у каждого сохраняются
  свои параметры страницы и колонтитулы; переносятся картинки, ссылки, сноски, примечания, списки и стили.
- **PDF**, а также чтение `.doc/.xls/.ods` — через LibreOffice; в Windows при его отсутствии
  используется установленный Microsoft Office. Для `.docx`/`.xlsx` без PDF ничего устанавливать не нужно.
- Тип файла определяется по содержимому, а не только по расширению; результат нельзя сохранить поверх исходного файла.
- Длительные операции можно отменить; зависшие конвертеры останавливаются по таймауту.
- **Контекстное меню проводника:** галочка в **⚙ Настройки** (или `merge-files.exe --install-menu`,
  убрать — `--uninstall-menu`). Выделите файлы → ПКМ → «Объединить файлы…»: все выбранные файлы откроются
  в одном окне, отсортированные по имени. Права администратора не нужны (запись в HKCU).
  В Windows 11 пункт находится в «Показать дополнительные параметры»; для 15 и более выделенных файлов
  Windows пункт не показывает — перетащите файлы в окно. Если переместить exe, включите пункт заново.

## Консольный режим
    merge-files -o result.pdf a.docx b.docx      # тип результата — по расширению .xlsx / .docx / .pdf
    merge-files --help

Журнал ошибок: `%LOCALAPPDATA%\MergeFiles\error.log`. Настройки: `%APPDATA%\MergeFiles\config.txt`.

## Сборка из исходников
