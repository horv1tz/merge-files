# Merge Files

Графическая утилита на Rust (egui): объединяет листы Excel или документы Word
в один файл того же типа либо в PDF.

## Возможности
- Excel (`.xlsx .xlsm .xls .ods`): выбор листов из каждого файла, порядок файлов, итог — `.xlsx` или PDF.
  Переносятся значения ячеек (формулы → вычисленные значения); стили и объединённые ячейки не переносятся.
- Word (`.docx`, `.doc`): документы идут друг за другом с разрывом страницы; картинки и гиперссылки
  переносятся, стили/нумерация/колонтитулы берутся из первого документа.
- PDF и чтение `.doc` выполняются через установленный LibreOffice.
- Перетаскивание файлов в окно, перестановка ⬆⬇, удаление.

## Запуск
    cargo run --release

Консольный режим (тип результата — по расширению):

    merge-files -o result.pdf a.docx b.docx
